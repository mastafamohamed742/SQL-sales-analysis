# Sales Data Analysis | SQL

## Project Overview

A SQL-based sales analysis project designed to analyze sales performance, customer activity, orders, and product performance.

The project demonstrates how SQL can be used to transform raw sales data into meaningful business insights and support data-driven decision making.

## Business Objectives

- Analyze overall sales performance.
- Measure total orders and customers.
- Calculate total sales and Average Order Value (AOV).
- Identify top-performing products.
- Analyze sales performance across countries.
- Understand sales trends and customer activity.
