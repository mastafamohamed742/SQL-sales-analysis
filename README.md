# Sales Data Analysis | SQL

## Project Overview

A SQL-based sales analysis project focused on analyzing orders, customers, products, and sales performance.

## Tools & Skills

- SQL Server
- SQL
- JOIN
- GROUP BY
- Aggregate Functions
- CASE
- Data Analysis

## Analysis Performed

- Overall sales KPIs
- Monthly sales trends
- Top-performing products
- Sales performance by country

## Key Metrics

- Total Sales
- Total Orders
- Total Customers
- Average Order Value (AOV)

## Project Purpose

The project demonstrates the use of SQL to transform sales data into business insights and support data-driven decision making.
